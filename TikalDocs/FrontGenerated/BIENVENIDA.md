## 🚨 Si Algo Sale Mal

### "npm no funciona"
→ Instala Node.js desde https://nodejs.org

### "npm install falla"
→ Ejecuta `npm cache clean --force` y intenta de nuevo

### "Puerto 5173 ocupado"
→ Cambia puerto en `vite.config.js` o cierra otra app

### "No veo cambios"
→ Recarga la página (Ctrl+Shift+R)

### "Más problemas"
→ Lee [GUIA_INSTALACION.md](GUIA_INSTALACION.md)
